Artikel Pemrograman Web

Mengenal HTML dan CSS untuk membuat website.

Pengenalan HTML

HTML merupakan bahasa markup yang digunakan untuk membangun struktur halaman website. HTML dapat membuat judul, paragraf, gambar, tautan, tabel, dan formulir.

Pengenalan CSS

CSS digunakan untuk mengatur tampilan halaman website, seperti warna, ukuran teks, jarak, posisi elemen, dan tata letak agar lebih rapi.
